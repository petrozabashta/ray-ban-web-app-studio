# Project instructions

- Общайся с пользователем по-русски и давай короткие проверяемые инструкции.
- Перед использованием API Meta сверяйся с официальной документацией и
  установленными типами пакета. Не придумывай возможности устройства.
- Для интерфейса очков используй `@wearables-ui-toolkit/mrbd` и его `App`,
  компоненты и встроенную D-pad-навигацию. Не добавляй собственную систему фокуса.
- Сохраняй доступность: понятные короткие подписи, видимый фокус, клавиатурное
  управление, корректный возврат и отсутствие ловушек фокуса.
- Делай минимальные связанные изменения и запускай проверки, относящиеся к ним.
  Не утверждай, что проверка или публикация выполнена, если этого не было.
- Не запрашивай камеру, микрофон или датчики без документированной необходимости.
  Помечай демонстрационные данные как DEMO/MOCK.
- Не добавляй секреты, токены, личные данные или `.env` в Git.
- Не создавай удалённый репозиторий, не отправляй push и не публикуй сайт без
  явного подтверждения пользователя.
