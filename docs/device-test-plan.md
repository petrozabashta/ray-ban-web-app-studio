- На 2026-11-13 URL ещё содержит ранее опубликованный commit `d33ace8`. Изменения этого этапа (статусы DAT и копирование диагностики) остаются локальными и на сайте пока отсутствуют. Их проверка на очках начнётся только после отдельного подтверждения commit/push/publication.

## Как открыть опубликованный Web App

1. Убедитесь в Meta AI, что очки подключены, и запишите точные версии ОС/приложения/прошивки.
2. Если пункт Web Apps доступен, включите Developer Mode согласно актуальному интерфейсу Meta AI.
3. В Meta AI откройте **App Settings → Apps → Web Apps → Connect Web App**, введите опубликованный HTTPS URL и сохраните.
4. Откройте появившееся приложение в app grid очков. Если меню отсутствует, URL отклоняется или приложение не запускается, остановитесь и запишите сообщение/экран и численные версии; не устанавливайте неизвестные SDK и не включайте ненужные разрешения.

Ожидаемый результат открытия — интерфейс проекта на дисплее очков. Это проверяет только доставку browser Web App. Установка URL не даёт ему доступа к camera/microphone raw stream.

## Доступ к функциям очков: что проверять и чего не ожидать

В текущем browser Web App нет Meta DAT:

- Камера очков: **не доступна этому проекту**; разрешение не запрашивается.
- Микрофонный аудиопоток: **не доступен этому проекту**; разрешение не запрашивается. Документированный spoken input для Web App — распознанный текст в поле, не raw audio.
- Состояние DAT-сессии/подключения очков: **не проверяется**.
- Управление display-компонентами через DAT: **не реализовано**.
- Движущийся видеоэлемент: только локальный синтетический browser WebRTC DEMO/MOCK; он не передаётся на другую пару.

Поэтому не пытайтесь тестировать «передачу камеры» через разрешения браузера или телефонную камеру. Отсутствие интеграции не равно отказу разрешения или разрыву реального соединения.

## Обезличенная диагностика

На экране **О приложении** или в ошибке DEMO/MOCK нажмите копирование диагностики. JSON содержит только версию MVP, бинарные browser capability/network/storage статусы, фиксированную категорию ошибки и фиксированные статусы DAT. Он не включает URL, user-agent, текст исключения, токены, localStorage-содержимое или видеокадры. Если копирование не поддерживается, приложение должно показать это, а не утверждать успех.

Для физического теста отдельно запишите численные версии устройства и краткие шаги/сообщение ошибки. Скрывайте личные данные из скриншотов и не отправляйте изображения, полученные с камеры.
