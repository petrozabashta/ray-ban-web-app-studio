# Проверка в Meta Ray-Ban Display Simulator

Симулятор — расширение Chrome для просмотра интерфейса и D-pad-подобного ввода. Он не эмулирует все возможности и ограничения настоящих очков.

1. Запустите приложение командой `npm run dev` и дождитесь локального URL.
2. Откройте этот URL в обычном Chrome, где установлено расширение [Meta Ray-Ban Display Simulator](https://chromewebstore.google.com/detail/meta-ray-ban-display-simu/jpjlmmodokemlepklkdbimceggpbjcll).
3. Нажмите значок расширения, чтобы открыть его симулятор.
4. Проверьте интерфейс в тестовой области 600×600.
5. Проверьте стрелки и Enter, заметность Toolkit-фокуса, возврат, длинные строки и отсутствие горизонтального переполнения.
6. Проверьте читаемость на разных фонах симулятора. Чёрная заливка не гарантирует непрозрачный фон аддитивного дисплея.
7. Для записи выберите **Viewport Recorder** в расширении и запишите воспроизводимый сценарий.
8. Сохраните полученный WebM и приложите его вместе со скриншотом к баг-репорту через [шаблон issue](../.github/ISSUE_TEMPLATE/bug_report.yml).

## Различайте видео и камеру

- Запись WebM в симуляторе — запись тестового viewport; это не запись камеры очков.
- Воспроизведение видео в веб-приложении — отдельная функция и в MVP отсутствует.
- Веб-камера компьютера может быть фоном симулятора, если такая возможность есть в установленной версии расширения; приложение не запрашивает её.
- Доступ к камере/видеопотоку очков и микрофону не реализован. Не выводите его наличие из работы симулятора или записи экрана; перед добавлением проверьте официальную документацию и нужный тип приложения.

В MVP нет mock-датчиков и фонового опроса. Для устройства проверьте опубликованный HTTPS URL через Meta AI/симулятор только если соответствующий пункт действительно доступен в установленной версии. Не конструируйте deep link вручную.
