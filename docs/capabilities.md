# Возможности и ограничения

## Реализовано и проверено в проекте

- React + TypeScript + Vite и Meta UI Toolkit `App`, `Page`, `Button`, `InputTextView`.
- Главный экран, чек-лист, экран клавиатурного управления и сведения о среде.
- Чек-лист: создание короткого пункта, отметка, следующий незавершённый пункт, локальное сохранение и подтверждение очистки.
- Unit tests для логики списка; browser tests работают против production preview.
- Локальный видеотест DEMO/MOCK: синтетический Canvas-сигнал проходит через браузерный WebRTC loopback и декодируется в локальный `<video>`; измеряется только частота показа кадров, а остановка освобождает дорожки и соединение. Камера, разрешения, backend и внешняя видеопередача не используются.
- Информация о версии, `navigator.onLine`, доступности localStorage и `window.isSecureContext`.
- Экран диагностики явно показывает отсутствие Meta DAT, незапрошенное разрешение камеры, непроверяемое подключение очков и не реализованный вывод на дисплей. По явному действию копируется обезличенный отчёт; URL, user-agent, exception text, секреты и видео не включаются.
- Официальный пример Snake хранится отдельно от приложения, запускается отдельной командой и не добавляет игровые зависимости в основной bundle.

## Доступно только в браузере/симуляторе

- `navigator.onLine` показывает состояние соединения по мнению браузера, но не гарантирует доступ к интернету.
- Локальное хранилище относится к текущему origin и браузерному профилю; очистка данных браузера удалит список.
- Simulator/Viewport Recorder и их фоны принадлежат расширению Chrome. Автоматизированные тесты проекта не загружают расширение.
- DEMO/MOCK проверяет браузерную медиатранспортировку, но не Meta DAT, SDK/permissions, камеру или реальный рендер дисплея очков. Для этих участков Meta предоставляет отдельный Mock Device Kit, который требует нативного DAT-приложения и платформенной тестовой среды.
- `window.isSecureContext` описывает контекст текущего browser URL, а не пригодность всех функций на очках.

## Требует проверки на очках

- Читаемость, фокус, навигация D-pad, сохранение и возврат на фактической прошивке/устройстве.
- Публичный HTTPS URL и добавление через Meta AI или опцию View on Glasses QR — только если они доступны в аккаунте и версии приложения пользователя.
- Реальный стартовый бюджет на канале и CPU устройства.

## Не реализовано

- Backend, аккаунты, синхронизация между устройствами, установка PWA/offline install.
- Реальный доступ к камере/микрофону очков, поток DAT, вывод на DAT-дисплей, сенсоры, WebMCP и фоновый сетевой опрос. Браузерный DEMO/MOCK не является реализацией этих возможностей.
- Автоматическая публикация. GitHub Pages и удалённый репозиторий настроены; deploy выполняется вручную через защищённый workflow.

Meta документирует DAT SDK-клиенты для iOS и Android. Руководство iOS отдельно предупреждает, что отправка DAT-клиента в Apple App Store сейчас не поддерживается и может быть отклонена из-за использования `ExternalAccessory`. Это ограничение нативной DAT-части; оно не является утверждением о публикации браузерного Web App по URL.

## Возможно требует нативного приложения

Если задача выходит за документированные возможности обычного Web App и требует Device Access Toolkit или прямого управления аппаратурой, это отдельный нативный этап. Текущая версия не предполагает, что iPhone-компаньон предоставляет такую функцию.
