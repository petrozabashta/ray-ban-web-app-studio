# Snake — отдельный upstream-пример Meta

Это пример `examples/snake` из [`meta-wearables-webapp`](https://github.com/meta/meta-wearables-webapp/tree/f39fa1ce687015e25f68a9b82791447d88ba584f/examples/snake), commit `f39fa1ce687015e25f68a9b82791447d88ba584f`. `index.html` и `styles.css` сохранены без изменений; в `app.js` добавлена только пауза игрового интервала при скрытии страницы и возобновление при возврате. Лицензия находится рядом в `LICENSE`.

Из корня проекта запустите `npm run snake`. Игра открывается по `/examples/snake/index.html` и остаётся отдельной от React-приложения и его production bundle. В исходнике используется собственный фиксированный игровой canvas 560×460 в 600×600 оболочке; это не шаблон адаптивного Toolkit-экрана.

Для автономной проверки можно открыть эту папку через любой локальный статический HTTP-сервер. Зависимости игры не устанавливаются.

Фоновые цвета и фиксированная геометрия исходного примера не заменены на Toolkit-стили; проверьте читаемость и прозрачность в симуляторе.
